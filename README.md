# Video Game Sales Data Analysis

This project analyzes a video game sales dataset using Python in Jupyter Notebook.

## Project goals

- Explore sales by region and country.
- Compare national vs global sales and profit.
- Visualize sales distribution using bar charts and pie charts.

## Tools used

- Python
- Jupyter Notebook
- pandas, numpy
- matplotlib, seaborn

## Files

- `VideoGamesAnalysis.ipynb`: main notebook with all analysis and visualizations.
- `VideoGamesSales.csv`: dataset used for the project.

## How to run

1. Clone or download this repository.
2. Open `VideoGamesAnalysis.ipynb` in Jupyter Notebook.
3. Make sure `VideoGamesSales.csv` is in the same folder.
4. Run the notebook cells from top to bottom.
